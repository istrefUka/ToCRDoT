# ToCRDoT

## Building and running the application
At first you must have npm installed. 
You can do this by installing the Node.js version manager (see [this link](https://www.freecodecamp.org/news/node-version-manager-nvm-install-guide/) for some guidance on that). 

With nvm installed, run:
```
nvm install 22.17.0
```
then, run 
```
nvm use 22.17.0
```
and then run ```node -v``` to check that your node installation works. 

In the root of this repository, run 
```
npm ci
``` 
to install all the packages. 

Then you can run 
```
npm run start
``` 
to start the application.
